# Internationalisation and RTL

## Space

- English strings of ≤ 10 characters expand 200–300% in translation; strings over 70 characters ~130% (IBM, via W3C). "Views" is 2.8× longer in German. Buttons, tabs, chips and nav labels get intrinsic widths and may wrap; primary action labels are never truncated.
- Thai and similar scripts can need ~150% of the vertical space of Latin text: line boxes grow with their content.
- Text never lives inside images.

## Strings

- Whole messages with named placeholders (ICU MessageFormat), never concatenated fragments: word order changes between languages.
- Plurals through `Intl.PluralRules` or ICU `plural`: languages have up to six categories (Arabic uses all six), so `n === 1 ? 'file' : 'files'` is always wrong.
- `Intl.NumberFormat` (numbers, currency, percent, compact), `Intl.DateTimeFormat`, `Intl.RelativeTimeFormat` ("3 hours ago"), `Intl.ListFormat` ("A, B and C").
- Names: one "Full name" field accepting any characters; if you must split, "Given names" and "Family name", never "First/Last". Address formats vary by country; drive fields from the country.

## Right-to-left

- Set `dir="rtl"` and `lang` on `<html>` in markup, not with CSS `direction`.
- Logical properties (`margin-inline-start`, `text-align: start`, `inset-inline-end`) mirror the layout automatically; physical `left`/`right` do not.
- Wrap user-generated or injected values (names, titles, numbers inside text) in `<bdi>` or give them `dir="auto"`.
- Mirror directional icons (back, forward, reply, send, list indent) with `:dir(rtl) .icon-dir { transform: scaleX(-1) }`. Media controls, progress through time, clocks, checkmarks and brand logos stay as they are. Nothing mirrors automatically on the web.

## CJK

- `word-break: auto-phrase` on Japanese and Korean headings avoids mid-phrase breaks (Chromium only); `word-break: keep-all` keeps Korean words whole.
- Line length cap for CJK prose is ~40 characters.
- Font stacks list a CJK fallback explicitly.
